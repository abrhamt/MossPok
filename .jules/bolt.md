## 2024-06-09 - Inline Object Props in Presentational Game Components
**Learning:** This codebase frequently passes inline object props (e.g. `card` object with `suit` and `rank`) from parent container components down to highly reused presentational game components like `PokerCard`. These inline object props create new object references on every update of the global game state, forcing expensive re-renders across the entire game UI tree (e.g. all cards on the table, all players' hands), even when the actual logical values (e.g. `suit` and `rank`) are identical.
**Action:** Always wrap these heavily rendered presentational game components in `React.memo` and provide a custom semantic comparison function (e.g. `areEqual`) that deeply checks the critical values (like `suit` and `rank` for cards) to break the re-render chain from the global state.
