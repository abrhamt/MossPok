## 2024-07-06 - PokerCard Re-renders and Dynamic Shallow Comparison
**Learning:** Presentational game components like `PokerCard` frequently receive inline object props (e.g., `card={{ suit, rank }}`) which change reference on every render, causing massive unnecessary re-renders of the entire poker table. When writing custom `areEqual` functions for `React.memo` to fix this, it's better to deep compare the specific nested objects (`card`) and use a dynamic shallow comparison (`Object.keys().filter(...)`) for the remaining props rather than hardcoding every prop name, preventing the memoization from breaking silently when new primitive props are added later.
**Action:** Always wrap frequently rendered list items in `React.memo`. When inline object props are unavoidable, use custom `areEqual` functions that semantically compare the problematic nested objects while dynamically shallow-comparing the rest to maintain robustness.
